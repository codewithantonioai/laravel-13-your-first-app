# Lesson 2 · Install the tools and create the app

▶ [Watch this lesson](https://youtu.be/Kzgubnx29fU?t=213) (starts at 3:33)

## Goal

Lesson two: we're going to install what we need and create the application we'll work on for the rest of the tutorial.

## Commands and files (as shown in the video)

### Terminal · instalar php

```bash
composer global require laravel/installer
```

### Terminal · crear app

```bash
laravel new notes
```

### Terminal · arrancar

```bash
cd notes
npm install && npm run build
composer run dev
```

## Recap

With that, you have the full environment and an application that boots. In the next lesson we open the project folder and see what's inside and where each request comes in.
